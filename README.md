# Fragmentation Calculator

## Overview

The Fragmentation Calculator is a Python-based desktop application developed to perform fragmentation calculations using standard engineering formulas. It provides a simple graphical interface where users can input parameters and instantly calculate fragmentation-related values.

This project was developed as part of a DRDO internship learning project.

---

## Features

* User-friendly GUI built with Python
* Fast and accurate fragmentation calculations
* Input validation
* Organized modular code structure
* Easy to extend with additional formulas

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/DRDO-project.git
cd DRDO-project
```

Install the required packages:

```bash
pip install numpy matplotlib
```

---

## Running the Application

Navigate to the project folder:

```bash
cd Fragmentation_calculator
```

Run the application:

```bash
python main.py
```
